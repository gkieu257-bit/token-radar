Token Radar ranks pre-token DeFi protocols by implied launch value. It reads a sealed DefiLlama snapshot, scores every pre-token protocol with the radar-2 model (category multiple, growth, maturity, chain breadth), and serves a static dashboard with a sortable board, per-protocol detail, farm steps, and a leaders-by-category strip.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
